# Kernel Headers

This directory contains all public kernel header files organized by subsystem.

## Directory Structure

- `arch/` - Architecture-specific interfaces
- `core/` - Core kernel services
- `sync/` - Synchronization primitives
- `proc/` - Process and thread management
- `mem/` - Memory management interfaces
- `util/` - Utility functions and data structures

## Phase 0-1 Headers

Essential headers for Phase 0-1:
- `types.h` - Basic type definitions
- `config.h` - Configuration constants
- `kprintf.h` - Kernel printf for debugging
